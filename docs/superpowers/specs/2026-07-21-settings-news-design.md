# Settings → Новости (changelog) — Design

## Problem

В настройках нет экрана с историей обновлений. Пользователю непонятно, какие фичи
появились и когда. Нужен простой changelog внутри приложения.

## Goals

1. Пункт «Новости» в настройках → отдельная страница `/news`.
2. На странице — список пользовательских фич, сгруппированных по датам (новые сверху).
3. Данные — статический массив в коде (без сети и без git на клиенте).

## Non-goals

- Автогенерация из git / CI.
- Бейджи «новое», unread-счётчики, push.
- Markdown-файл или CMS.
- Изменение логики настроек, бэкапа, анализа еды.

## Architecture

### Route

- `src/app/router.tsx`: `{ path: '/news', element: <ProfileGuard><NewsPage /></ProfileGuard> }` внутри `AppShell`.
- Назад с `/news` → `/settings`.

### Settings entry

В `SettingsPage`, секция после «Данные» (перед DEV-блоком):

- Кнопка/ряд «Новости» на всю ширину → `navigate('/news')`.
- Иконка `ChevronRight`, стиль как у навигационных рядов в приложении (outline button или
  `button` ghost row с текстом слева и шевроном справа).

### `features/news`

```
features/news/
  model/changelog.ts   # данные + тип NewsRelease
  index.ts             # export { NEWS_CHANGELOG, type NewsRelease }
```

```ts
export interface NewsRelease {
  date: string;       // YYYY-MM-DD
  title: string;
  items: string[];
}

export const NEWS_CHANGELOG: NewsRelease[];
```

Сортировка массива: по `date` убыванию (новые первые). Даты форматировать на UI через
`toLocaleDateString('ru-RU', { day: 'numeric', month: 'long', year: 'numeric' })`.

### `pages/news`

```
pages/news/
  ui/NewsPage.tsx
  index.ts
```

`NewsPage`:

- Шапка: back → `/settings`, заголовок «Новости».
- `main`: для каждого релиза — дата (muted), title (semibold), `ul` с `items`.
- Без декоративных карточек; spacing как на `SettingsPage` (`space-y-6` / `space-y-8`).

## Testing

- Юнит-тест на `NEWS_CHANGELOG`: не пустой; даты ISO `YYYY-MM-DD`; у каждого релиза
  `title` и хотя бы один `item`; массив отсортирован по убыванию даты.
- Ручная проверка: Настройки → Новости → список → Назад в настройки.

## Out of scope for follow-ups

- Deep links на конкретный релиз.
- i18n-файлы (остаёмся на захардкоженном RU, как остальной UI).
