## Gaps this plan closes

1. **PWA missing:** no `vite-plugin-pwa`, no `public/` icons/manifest, no SW registration, no `viewport-fit=cover` / safe-area.
2. **Meal Detail cramped:** user report «мало места / не влезает» — thicken/space «Полезность» / «Точность» bars and page padding to match screenshot (labels + green bars under date, then vitamins, green calories, portions, 2×2 macros with mini bars).

## Locked decisions

- **D-01 PWA path:** Web PWA via `vite-plugin-pwa` (devDependency) + generated manifest + `registerType: 'autoUpdate'`. Not a Capacitor rewrite. Package treated as [ASSUMED] legitimate (official vite-pwa org; pin a current Vite-5-compatible version from npm at install time).
- **D-02 Manifest copy:** `name` / `short_name` «AI Food», `lang: 'ru'`, `display: 'standalone'`, `theme_color` / `background_color` aligned with existing `#10b981` / primary emerald, `start_url: '/'`, icons 192 + 512 in `apps/mobile/public/`.
- **D-03 Safe-area:** `viewport-fit=cover` in `index.html`; replace hardcoded `pt-12` on `DailyHeader` with `pt-[max(3rem,env(safe-area-inset-top))]` (or equivalent); pad Home FAB and Meal Detail header/bottom with safe-area insets.
- **D-04 Meal Detail layout only:** Do not change AI schema, validators, or persistence of `healthiness` / `confidence`. Only restyle `MealSummaryEditor` + `MealDetailPage` spacing/typography to match screenshot: Russian labels «Полезность» / «Точность», value as `N/10` and `N%`, thicker emerald bars, more vertical rhythm, macros always `grid-cols-2` (remove `sm:grid-cols-4` squeeze on wider phones if it fights the screenshot 2×2).
- **D-05 Out of scope:** Rebuilding favorites, retry, stats charts, settings forms, new micronutrient logic, or Capcitor native packaging.

## Discretion

- Simple solid-color or emoji-derived PNG icons are fine if no designer assets exist; must be real files referenced by the manifest.
- Prefer `virtual:pwa-register` autoUpdate over custom update UI.
- Leave Stats/Settings pages alone unless a one-line safe-area header pad is trivial and needed for consistency.
