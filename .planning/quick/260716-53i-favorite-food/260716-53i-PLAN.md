## Locked decisions (honor exactly)

- **D-01 Storage:** Favorites are local-only via Zustand `persist` + `capacitorStorage` (same pattern as `useDiaryStore` / `useSettingsStore`). Persist key `ai-food-favorites`. No API, no shared-types backend contract.
- **D-02 Add surface:** Toggle on `MealDetailPage` header (star icon next to delete). Russian aria-labels: «Добавить в избранное» / «Убрать из избранного». Toast on add: «Добавлено в избранное»; on remove: «Удалено из избранного».
- **D-03 Quick-add surface:** In `AddFoodSheet` menu, add button «Избранное» (Star icon). Opens in-sheet list mode. Tap a favorite → add meal to diary for current `selectedDate` → close sheet. Empty state copy: «Пока нет избранного. Добавьте блюдо на странице приёма.»
- **D-04 Snapshot semantics:** Favorite stores a copy of meal nutrition at toggle-on time (`name`, `items`, `totalCalories`, `portions`, optional `imageUri` / `healthiness` / `confidence` / `micronutrients`). Edits to the original meal later do not auto-update the favorite. Match toggle state by `sourceMealId === meal.id`.
- **D-05 Quick-add Meal:** New `Meal` with fresh `id`, fresh `FoodItem.id`s (deep-copied macros/grams), `timestamp` via `timestampForSelectedDate(selectedDate)`, `status: 'ready'`, reuse favorite `imageUri` reference if present (do not re-save file). No AI call.
- **D-06 Scope:** Only `status === 'ready'` (or missing status treated as ready) meals can be favorited. Analyzing/error meals: hide or disable the star. No favorites management page beyond list-in-sheet + toggle; no drag reorder; no sync.

## Discretion

- Place domain type `FavoriteFood` in `features/favorites/model/favoriteFood.ts` (not `packages/shared-types`) — client-only template.
- Cap favorites list length at 50; if at cap when adding, toast.error «Достигнут лимит избранного (50)» and do not add.
- Cross-feature import `add-food` → `favorites` is allowed here (same pattern as `save-meal` → `settings`).
- List row UI: name + kcal via existing formatters/badges; keep compact; no need to reuse full MealCard.

## Patterns

- FSD barrels: export public API only from `features/favorites/index.ts`; pages/features import `@/features/favorites`
- Co-located Vitest; Russian UI; 2-space indent; single quotes
- Do not put favorites into `useDiaryStore` — separate persist slice
