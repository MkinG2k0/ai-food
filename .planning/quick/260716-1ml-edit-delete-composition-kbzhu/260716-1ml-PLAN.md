## Locked decisions (do not reopen)

**D-01 — Source of truth:** `Meal.items[]` владеет макросами. После каждой мутации item: `totalCalories = sum(items[].calories)`. Верхние Б/У/Ж всегда из sum items.

**D-02 — Item edit:** number-инпуты calories/protein/carbs/fat (+ name text, cheap). Persist через diary store on change или blur (Zustand persist, без API).

**D-03 — Item delete:** swipe left (framer-motion; thresholds как `SwipeableMealCard`: offset 80 / velocity 500) + trash на карточке; confirm BottomSheet; пустой `items[]` разрешён (totalCalories=0, empty composition UI); meal НЕ удалять автоматически при пустом составе.

**D-04 — Dish-level KBJU:** верхняя карточка — editable inputs для name + calories + protein/carbs/fat. Правка блюдового нутриента → пропорциональный scale всех items по этому полю (если sum==0 и есть items — всё значение на first item; если items пуст — no-op). Meal delete оставить как есть (header + bottom + DeleteMealConfirmSheet).

**D-05 — Store API:** явные методы `updateMealItem`, `removeMealItem`, `updateMealNutrition` (+ name через существующий `updateMeal` или тонкий хелпер). Unit-тесты обязательны. Feature slice `features/edit-meal`; page только компонует. Cross-slice imports только через barrels.
