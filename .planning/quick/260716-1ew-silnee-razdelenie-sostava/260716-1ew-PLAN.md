Фото: гамбургер + картофель фри. Состав сейчас:

## Target prompt rule (discretion)

Экспортировать константу `COMPOSITION_PROMPT_RULE` (как `FOOD_NAME_PROMPT_RULE`) и вставить её в `SYSTEM_PROMPT` рядом с существующим правилом состава. Текст правила должен явно содержать:

1. Составные/слойные блюда (бургер, сэндвич, ролл, шаурма, пицца с начинкой, салат как сборка) — всегда разбивать на видимые ингредиенты/слои в `items[]`.
2. Конкретный пример: бургер → отдельные items вроде булка, котлета, сыр, салат/зелень, помидор — запрещено оставлять один item с именем блюда вроде «Гамбургер» / «Бургер», когда на фото видны слои.
3. Простые единичные продукты (картофель фри, яблоко, стакан сока) — один item допустим.
4. `foodName` = название всего приёма; `items[].name` = атомарные компоненты — не дублировать название составного блюда как единственный item, если видны части.
5. Топы calories/protein/carbs/fat/fiber по-прежнему = сумма по items.

Также уточнить schema-строку у `items[].name` в SYSTEM_PROMPT: не только «отдельного видимого компонента», а «атомарного видимого ингредиента/слоя составного блюда».
