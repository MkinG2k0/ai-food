<interface>
Contracts this plan creates. Implement these names and shapes; do not invent parallel APIs.

ensureUserReferralCode(prisma, user): Promise&lt;string&gt;
- desired nick = normalizePromoCode(username with leading @ stripped); empty username → no nick (D-01, D-02)
- fallback = `u` + last 8 alphanumeric chars of user.id, lowercase; if that key is taken as PromoCode or another User.referralCode, retry last 10 then 12 then 16 of the same alnum id
- if nick collides with PromoCode or another user's referralCode, persist/keep fallback instead (D-02)
- if username appears later and nick is free, switch referralCode to the nick so the old fallback stops matching (D-02)
- persist User.referralCode when it changed; return the stored code

ResolvedPromo gains source: `admin` | `referral` and optional referrerId
- REFERRAL_DISCOUNT_PERCENT = 10
- resolvePromo: lookupPromo (admin catalog) first; else User.findUnique by referralCode; else null (D-05)
- unknown / empty still null → billing keeps INVALID_PROMO (D-05)

GET /billing/referral (X-User-Token, same requireUser as other billing routes) (D-07)
- 401 without token
- calls ensureUserReferralCode so already-logged-in users get a code without re-login (D-01)
- 200 { code: string, conversionCount: number } where conversionCount = Payment count with promoCode === code AND status === confirmed (D-04)

grantReferralRewardIfNeeded(prisma, payment): Promise&lt;void&gt;
- REFERRAL_REWARD_DAYS = 30
- no-op if payment.referralGrantedAt is set, promoCode empty, promo is an admin PromoCode, no matching referrer, or referrer.id === payment.userId
- else: if referrer hasActiveSubscription, add 30 UTC days to subscriptionExpiresAt; else set subscriptionStatus=active and expiresAt = now + 30d (D-03)
- set payment.referralGrantedAt in the same transaction as the user update
- do not change activateYearLicense (referee still gets a year from paidAt)

SELF_REFERRAL: 400 when resolved.source === referral and referrerId === subscriber id on /promo/validate and /subscribe (D-07). ApiError message: Нельзя использовать свой промокод (SubscribePage already toasts message).
</interface>
