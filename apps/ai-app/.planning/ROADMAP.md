# Roadmap

## Milestone: OpenAI Gateway

### Phase 1: Standalone OpenAI API service
**Goal:** Adapt the extracted monorepo food-analysis backend into a reusable OpenAI gateway with REST endpoints for any consuming app.

**Success criteria:**
- [ ] Project builds and runs without workspace packages
- [ ] Core OpenAI capabilities exposed as HTTP endpoints
- [ ] Shared error contract and health check
- [ ] Tests cover main happy paths and error mapping
