<objective>
Add Capacitor ML Kit barcode scanning on Android while keeping the web LiveBarcodeScan fallback.

Purpose: WebView BarcodeDetector on Android APK is weak/laggy; native ML Kit gives reliable point-and-scan without changing OFF/save flow (per D-01, D-02, D-03).

Output: Dual-path `/scan?mode=barcode` — continuous `startScan` on native Android, unchanged web path elsewhere; food camera mode intact.

**Chosen UX (Claude's Discretion):** continuous `BarcodeScanner.startScan` + `barcodeScanned` listener — NOT ready-to-use `scan()`. Shared getUserMedia cannot share the camera with ML Kit simultaneously, so native barcode mode **takes camera ownership**: stop the WebView stream, make the WebView transparent, run ML Kit behind the UI chrome; on leave barcode / enter food / confirm / unmount — `stopScan`, restore opacity, allow getUserMedia again. This preserves continuous point-and-scan like web without RTU modal.
</objective>
