<interface>
## Server (apps/ai-app)

### Env
- `OPENROUTER_MODEL` — default model id; fallback `google/gemini-3-flash-preview` (matches current frontend DEFAULT_AI_MODEL)
- Temperature: hardcode `0` in `modelConfig.ts` (current client `temperatureForModel` always returns 0)

### Routes (mount under `/v1` after `requireApiKey`, each with `enforceChatQuota`)
- `POST /v1/food/analyze` — SSE OpenAI-compatible stream (same chunk shape as `/v1/chat/completions` stream)
- `POST /v1/food/refine` — JSON chat.completion (non-stream), `response_format: json_object`
- `POST /v1/food/ask` — JSON chat.completion (non-stream); covers settings custom-content + question modes

### Analyze request body (Zod)
```
{
  images?: string[];          // data-URL strings after client compress
  description?: string;
  customInstructions?: string;
  dietType?: 'none'|'halal'|'vegan'|'vegetarian';
  features?: { vitamins?: boolean; healthiness?: boolean; composition?: boolean };
}
```
Reject if no images and empty description. Do not accept `model`, `temperature`, `messages`, `system`.

### Refine request body
```
{
  correction: string;
  mealContext: { name?: string; items: Array<{name,calories,protein,carbs,fat,grams}> };
  imageDataUrl?: string;      // optional data: URL
  customInstructions?: string;
  dietType?: ...;
  features?: AnalyzeFeatures;
}
```

### Ask request body
```
{
  mealContext: { name?: string; totalCalories: number; items: [...] };
  customInstructions?: string;  // settings slide
  question?: string;            // follow-up slide
}
```
If both empty → 400 or return empty assistant content consistently with client early-return `''` (prefer: client keeps early return; server validates at least one when called).

### Response
- analyze: `text/event-stream` deltas; client accumulates text then `parseNutritionXml`
- refine/ask: standard OpenAI completion JSON (`choices[0].message.content`); client keeps `parseJsonContent` / `normalizeCustomContent` / off-topic guards

### Usage kinds (X-Usage-Kind headers unchanged)
- analyze → existing resolveAnalyzeUsageKind values
- refine → `refine`
- ask → `other`

## Client clean contracts
- Stop passing `model` from hooks/stores into these three APIs (Settings `aiModel` UI may remain persisted but unused by food calls in this task — do not remove Settings UI).
- Keep: `compressImageForAi`, data-URL conversion, XML/JSON parse, `maskNutritionResultByFeatures`, `foodTopicGuard` prechecks, quota headers, auth.
</interface>
