# Quick Task 260716-i2n: No-food detection error and retry

## Goal

When a photo does not contain edible food (people, animals, unclear images, etc.), show a recognition error with retry instead of saving a fake meal entry.

## Tasks

### 1. Prompt + API rejection
- Add `NO_FOOD_PROMPT_RULE` instructing model to return `{ noFood: true, reason }` for non-food images
- Parse `noFood` in `analyzeFoodApi` and backend `analyze-food` route → `422 NO_FOOD_DETECTED`

### 2. UI error state
- Store `analyzeErrorCode` on failed meals
- Show «На фото не обнаружена еда…» + existing «Повторить» button in `MealCard`

### 3. Tests
- `analyzeFoodApi`, `nutritionResultSchema`, `useSaveMeal`, backend route
