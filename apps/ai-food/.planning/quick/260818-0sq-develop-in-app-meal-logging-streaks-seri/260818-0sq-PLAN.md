## Freeze / streak algorithm (executor: implement exactly)

Inject now: Date into applyStreakState for tests.

Counted keys: unique localDateKey(new Date(meal.timestamp)) for meals passing D-01.

Covered = counted ∪ consumedFreezeDateKeys.

Today T = localDateKey(now). Yesterday Y = localDateKey of the local calendar day before T (construct with new Date(y, m, d - 1), not +ms).

Current-run walk:
- If T is counted, start at T. If T is not counted, start at Y and do not consume a freeze for Y while T is still uncounted (today still in progress).
- Walk older days one by one. Counted or already in consumedFreezeDateKeys continues the run.
- On a gap day G: look at the next older day O. If O is covered and freezeCount > 0 and G is not already consumed, propose consume G (single miss after the user has a counted day on the newer side). If O is also a gap, break the run and do not consume (two-plus consecutive misses).
- Consume at most one freeze per applyStreakState call.
- While T is uncounted, a gap at Y is not consumed.

Grant: if resulting currentLength hits 7, 14, 30, 60, or 100 and that number is not in grantedMilestones and freezeCount < 2, grant +1 and add the milestone. Milestone 3 is display-only (D-07), not a freeze grant (D-08).

bestStreak = max(persisted bestStreak, currentLength, longest covered run found in history using already-consumed freeze dates only — do not spend new freezes to inflate history). Persist that max so deleting old meals does not shrink the record.

shouldCelebrate: T is counted AND lastCelebratedLocalDate !== T AND currentLength >= 1 (today just counts). Refresh the same local day after markCelebrated must yield shouldCelebrate false (D-05).

Week: seven dates from getWeekStart(now) (shared/lib, Monday). Each filled iff that local key is covered (D-06). Future days this week stay empty until counted or frozen.

Next goal: previous milestone = largest of 0∪[3,7,14,30,60,100] that is <= currentLength. Next = smallest milestone > currentLength. remaining = next - current. bar = (current - previous) / (next - previous). If currentLength >= 100, next is null, remaining 0, bar 1, copy that 100 is achieved (D-07).

Streak start date: oldest day of the current covered run (Date at local noon). Empty meals → currentLength 0, no start.
