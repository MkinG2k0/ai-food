- Cross-slice imports only through FSD `index.ts` barrels.

- Do not store API responses in Zustand; diet is client preference only.

- **D-01:** Diet options (single-select only): `none` / Без ограничений, `halal` / Халяль, `vegan` / Веган, `vegetarian` / Вегетарианство. Do not add other diet kinds.
- **D-02:** Pork-lookalike → chicken bias applies **only** when `dietType === 'halal'`.
- **D-03:** Persist preference; inject into analyze-food system prompt (client gateway path).
