## Target schema (discretion locked for executor)

Добавить в `packages/shared-types/src/index.ts`:

```ts
export interface NutritionItem {
  name: string;
  calories: number;
  protein: number;
  carbs: number;
  fat: number;
  portion?: string;
  fiber?: number;
}

export interface NutritionResult {
  foodName: string;
  calories: number;
  protein: number;
  carbs: number;
  fat: number;
  fiber: number;
  confidence: number;
  items: NutritionItem[];
}
```

Top-level fields = итоги всего приёма (для NutritionCard / totalCalories). `items` = состав. Промпт требует: totals ≈ сумма items; имена на русском.
