# Quick: экспорт/импорт JSON

## Goal

В настройках — кнопки экспорта и импорта пользовательских данных (дневник, профиль, настройки, избранное, вес) в один JSON-файл.

## Scope

- Экспорт: скачивание `ai-food-backup-YYYY-MM-DD.json`
- Импорт: выбор `.json`, валидация `version`, подтверждение замены, применение во все persist-сторы
- Не включать: model-test store, ephemeral image store
