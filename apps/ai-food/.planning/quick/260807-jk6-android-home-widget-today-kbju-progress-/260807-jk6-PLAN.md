## Capacitor Preferences (verified in Cap 8 sources)

- Default SharedPreferences **group/file name**: `CapacitorStorage` (`PreferencesConfiguration.DEFAULTS.group`)
- Keys are stored as plain string keys (no Cap prefix) — use key `ai-food-widget-kbju`
- Value: JSON string `{ date, consumed:{kcal,protein,fat,carbs}, goals:{kcal,protein,fat,carbs} }`
- `date`: local calendar `YYYY-MM-DD`. If native date ≠ snapshot.date, render consumed=0 but still show goals from snapshot (or FALLBACK hex goals if missing)

## Color hex targets (Android colors.xml)

Map Tailwind/CSS tokens approximately:
- kcal / primary: `#10B981` (app `--primary` ≈ hsl 160 84% 39%)
- protein: `#FB7185` (rose-400)
- fat: `#FBBF24` (amber-400)
- carbs: `#0EA5E9` (sky-500)
- over-goal / destructive: `#EF4444`
- track/muted: `#E4E4E7`
- card bg: `#FFFFFF`; label: existing `widget_label` / `#18181B`

## Architecture

```
DailyHeader math (JS) → Preferences ai-food-widget-kbju → KbjuRingsWidgetProvider
                      ↘ KbjuWidget.refresh() → AppWidgetManager.notify/update
```

Custom plugin (local Java only, no new npm package): `@CapacitorPlugin(name = "KbjuWidget")` with `@PluginMethod refresh`. Register in `MainActivity.onCreate` with `registerPlugin(KbjuWidgetPlugin.class)` **before** `super.onCreate(...)`. JS: `registerPlugin` + no-op web implementation.

RemoteViews cannot run custom Views/SVG — draw each ring with `Canvas`→`Bitmap`→`setImageViewBitmap`.

FSD: pure compute in `shared/lib` (uses `@ai-food/shared-types` + `isSameDay` only). Store subscription + plugin call live in `features/kbju-widget` with barrel `index.ts`. Mount sync UI in `AppShell` via barrel import.
